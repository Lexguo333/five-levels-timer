Il percorso

Completa 5 sessioni di un livello per sbloccare il successivo. Una sessione vale se disegni almeno l'80% delle pose.

Libreria reference

Una corsia per livello. Scegli la destinazione, poi aggiungi file o importa una board Pinterest. Puoi buttare tutto in “Da smistare” e spostare dopo con i numeri o trascinando.
